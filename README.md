# SnackLab 🍓

> Crea tu snack, a tu manera.

## Descripción

SnackLab es un emprendimiento de cajas de snacks personalizadas. Esta aplicación
web es un MVP visual construido con HTML5 y CSS3 que presenta la marca y guía al
usuario hacia la acción principal: **crear su propia SnackBox**.

## Problema

Comprar snacks para una ocasión específica es fragmentado: hay que buscar y
combinar productos por separado, sin una experiencia pensada para el momento
(una noche de película, un regalo, estudiar).

## Solución

SnackLab permite conocer diferentes tipos de snacks y armar una caja según la
ocasión, las preferencias y el presupuesto del usuario.

## Propuesta de valor

Una forma sencilla, divertida y personalizada de crear una caja de snacks.
